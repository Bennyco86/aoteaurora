# AOTEAURORA

Official product, store-status, privacy and support site for **AOTEAURORA**, a commercial New Zealand-focused southern-lights app developed, published and operated by **AOTEAURORA LIMITED**.

**Base price:** USD 8.99

## Store status

- **Google Play:** listing in progress; official link coming soon.
- **Apple App Store:** release planned; official link coming later.

## What is here

- the story and science behind the app;
- a plain-language description of how viewing conditions are assessed;
- current project status;
- [support and troubleshooting](SUPPORT.md); and
- the [privacy notice](PRIVACY.md).

## What is not here

This repository does **not** contain the app, its private source code, preview access, builds or direct installation packages. Official distribution will be through the store links published on the website.
