# AOTEAURORA

Public background, privacy and support site for **AOTEAURORA**, a New Zealand-focused southern-lights viewing companion in development by Aotearoa Labs.

## What is here

- the story and science behind the project;
- a plain-language description of how viewing conditions are assessed;
- current project status;
- [support and troubleshooting](SUPPORT.md); and
- the [privacy notice](PRIVACY.md).

## What is not here

This repository does **not** contain the app, its private source code, preview access, builds or installation packages. No public release should be inferred from this support repository.
