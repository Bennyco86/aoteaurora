AOTEAURORA / Privacy

Clear by design

Privacy without the fog.

What the current early-stage project uses, what it does not use, and the choices that stay with you.

On this page

Summary Information used External services Your choices Contact

The short version.

AOTEAURORA’s current early build has no account system, advertising or analytics code. It does not sell personal information. Location is optional and used to make the viewing guidance relevant to your part of New Zealand.

Notifications are not currently active.

The interface may refer to planned aurora alerts, but push subscription is disabled while the feature and its privacy model are being tested.

Information the project uses.

Location, when you choose it

If you select automatic location and grant permission, the browser or device provides latitude and longitude so AOTEAURORA can calculate local thresholds, darkness and weather conditions. In the current build, an automatically detected location is held in working memory and is not written to local storage. You can deny permission and use a preset location where available.

Coordinates—whether from a preset or automatic location—are sent directly to Open-Meteo in order to request the corresponding local weather and air-quality forecast.

Data kept on your device

The current build may keep small preferences and operational caches in browser or app storage—for example language, preview-access state, recent alert metadata and same-origin application files. Clearing the app or site data removes this local information.

Support messages

If you email the developer or open a GitHub issue, the information you choose to include is used to answer the request and improve the project. Public GitHub issues are visible to others, so remove personal information before posting.

What is not present in the current build

  • no AOTEAURORA user account or profile;
  • no advertising network;
  • no behavioural analytics system; and
  • no active push-notification subscription.

External data and services.

The project requests scientific or forecast information from services including NOAA’s Space Weather Prediction Center, GeoNet / Earth Sciences New Zealand and Open-Meteo. GitHub hosts this support site and its public issue tracker. The provider hosting an active preview may also process routine web requests. Each service handles information under its own terms and privacy policy.

Data feeds may receive standard connection details such as your IP address. A weather request also contains the coordinates required to return a local forecast. AOTEAURORA is independent and is not endorsed by these providers.

Your choices and control.

  • Do not grant location access, or revoke it in browser or operating-system settings.
  • Use a general preset location instead of automatic location where that option is available.
  • Clear local site or app data to remove saved preferences and cached state.
  • Do not include precise coordinates or other personal information in public support reports.

Retention

Local preferences remain until you clear them or remove the app data. Support correspondence is kept only as reasonably needed to respond, maintain support records and improve the project. Public GitHub content follows GitHub’s controls and retention practices.

Children

AOTEAURORA is not designed to create profiles about children. A parent or guardian should help a child decide whether to enable location or send a support message.

Security and changes

Reasonable care is taken with the project, but no internet-connected service can promise absolute security. This notice will be updated if a public release adds accounts, active notifications, analytics or another material data practice.
